# Store listing — English (default)

Use this text for both addons.mozilla.org (AMO) and the Chrome Web Store.

## Name

Tabs to Markdown for AI

## Summary

AMO "Summary" field (max 250 characters). The Chrome short description comes from the manifest (`extDescription`).

> Turn tab groups, selected tabs or pasted links into clean Markdown files for ChatGPT, Claude, Gemini and other AI assistants. Adds a product summary (price, rating, specs, reviews) when the page provides one. Works locally.

## Description

Researching a product with an AI assistant? Copying pages by hand is slow, and AI tools often can't open shop pages themselves. Tabs to Markdown for AI reads the pages in your own browser, as you see them, and saves them as clean Markdown files you can upload to ChatGPT, Claude, Gemini, DeepSeek, Qwen or any other assistant.

**What it does**

- **From tabs:** a tab group, the tabs you selected (Ctrl/Shift-click), all tabs in the window, or only the current tab.
- **From links:** paste a list of links. Each one is opened in the background, read and closed.
- **One combined file:** all pages in a single Markdown file with a table of contents. Optionally, one file per page as well.
- **Product summary:** when a page contains structured product data, the file starts with a table of price, availability, rating, seller, specifications and sample reviews. Price-comparison pages also get a seller price list.
- **Clean text:** menus, cookie banners, ads, link lists and images are removed.
- **Folder names that remember:** files go to Downloads/&lt;folder&gt;. The name is suggested from the tab group name or the page titles. The extension remembers which pages you saved where, so when you add a new tab to an earlier research, the same folder is suggested.
- **11 languages:** English, Turkish, Spanish, Portuguese (Brazil), French, German, Russian, Chinese (Simplified), Japanese, Arabic and Hindi. The interface and the generated files follow your browser language.

**Privacy**

Everything happens on your computer. The extension has no server, sends no data anywhere and contains no analytics. Pages are read only when you start a job. Access to websites is requested the first time you use it.

**Good to know**

- Some sites show a "verify you are human" screen. The extension does not try to get past it: open the tab, complete the check yourself, then capture it again.
- PDF viewers and the browser's own pages can't be read.
- Prices and stock are the ones shown at the moment of saving.
